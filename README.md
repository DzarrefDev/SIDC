# SIDC-Sistema-Inteligente-de-Detec-o-de-Capacete-EPI-
O SIDC é um sistema de monitoramento inteligente que detecta em tempo real quando uma pessoa está sem capacete (EPI) em áreas industriais e de risco. Utiliza IA, visão computacional e uma interface web moderna para oferecer uma solução robusta e eficiente, aumentando a segurança operacional.
